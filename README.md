# DSA Fun - Data Structures & Algorithms Practice App

A modern Android app built with Kotlin and Jetpack Compose for practicing Data Structures and Algorithms problems.

## 🚀 Features (Planned)

- **Problem Bank**: 150 curated DSA problems across multiple topics
- **Code Editor**: Built-in syntax highlighting and auto-indent
- **Progress Tracking**: XP system, levels, and streaks
- **Analytics**: Visual charts and heatmaps of your progress
- **Focus Timer**: Pomodoro-style timer for focused practice
- **Gamification**: Badges, achievements, and milestones
- **Daily Challenges**: Keep your streak alive
- **Home Widget**: Quick access to stats

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose + Material3
- **Architecture**: MVVM + Clean Architecture
- **DI**: Hilt
- **Database**: Room
- **Navigation**: Navigation Compose
- **Async**: Coroutines + Flow
- **Local Storage**: DataStore
- **Background Work**: WorkManager
- **Widgets**: Glance

2. Open in Android Studio (Hedgehog or later)
3. Sync Gradle
4. Run on device/emulator (API 26+)
